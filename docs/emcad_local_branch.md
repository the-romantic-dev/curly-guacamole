# EMCAD + локальная ветка 1024

Рецепт: `configs/local.yaml`.
Ноутбук: `notebooks/train.ipynb (выберите experiment = "local")`.

## Архитектура

- Глобальный RGB: 640×640, PVT-v2-B2 → текущий forensic fusion → EMCAD, 64×160×160.
- Текущие 12 DCT-карт и forensic-ветка сохранены. Таблица Pillow всегда интерпретируется в natural-порядке; переключателя нет.
- Локальный вход: 15×1024×1024. Первые 3 канала — RGB с ImageNet-нормализацией; остальные — подписанные dx/dy и их модули для Y, Cr, Cb, полученных `cv2.COLOR_RGB2YCrCb` из float RGB [0,1]. Разности вычисляются до resize, с повторением крайнего пикселя на границе.
- Разрешение каждой оси уменьшается area-интерполяцией и увеличивается bilinear. Модули разностей вычисляются до усреднения, чтобы сохранить энергию противоположных откликов.
- Локальная CNN: 24×512×512 → 48×256×256 → 96×128×128; stride-8 признаки возвращаются на stride 4 и объединяются с локальным skip. Используются depthwise + pointwise свёртки, GroupNorm и GELU.
- Признаки EMCAD проецируются 64→32 и интерполируются на 256×256; объединяются с 48 локальными каналами. Далее локальный stride-2 skip помогает получить 64×512×512 признаков для существующей segmentation head.
- Main logits 512×512 интерполируются на 640×640 для существующего loss/validation API. При inference вероятности восстанавливаются до исходного размера, затем применяются прежние пороги и gate.
- Auxiliary head обучается только на локальных признаках 256×256, не зависит от PVT, coarse logits или ROI. Она заменяет global auxiliary head, возвращаясь через существующий `aux_logits` API. При inference не вычисляется.

## Обучение и геометрия

Шесть эпох, fixed train/development-протокол, originals в train, BCE на всех масках + per-image Dice только на позитивных, вес Dice 1.0. Auxiliary имеет вес 0.4, классификация — прежний 0.3. Число показов, sampling и расписание наследуются от базового рецепта; `resume: false` создаёт новый запуск.

Геометрия общая: исходный кадр → JPEG augmentation → существующий DCT → общий crop/rotate/flip. Затем фотометрические преобразования применяются один раз **до** уменьшения изображения; из результата получаются local RGB/residual и global RGB. DCT сохраняет прежний контракт до photometric augmentation. Это перенос photometric stage относительно старого pipeline; учитывать его при интерпретации абляции. Режим local поддерживает только stretch; letterbox отклоняется явно.

При `model.local_image_size: 0` сохраняются прежние модель и preprocessing. В snapshots текущего pipeline отсутствие настройки local_image_size означает 0; исторические snapshots без версии emcad_v1 отвергаются. Новый путь требует явного `local_input`; модель не подменяет отсутствующий локальный вход увеличенным global RGB. Смена локального размера при resume запрещена. Отдельные старые decoder-refinement варианты с ним не комбинируются.

## Вычислительный бюджет

Подсчёт `torch.utils.flop_counter.FlopCounterMode`, batch 1, eval, meta:

| Модель | GFLOPs |
|---|---:|
| PVT-v2-B2 + EMCAD + DCT, 640 | 89.564847936 |
| Та же глобальная модель + local 1024 | 96.630546240 |
| Добавка | 7.065698304 |

Остаток до лимита 100: 3.369453760 GFLOPs. Считается полный forward с обеими ветками и inference-головами. CPU preprocessing не включён в FlopCounterMode; его стоимость и передачу дополнительных входов нужно включать в end-to-end latency. `count_gflops` временно переводит модель в eval и восстанавливает режимы, не изменяя BN buffers.

В новой local-ветке 42 177 параметров (включая обучающую голову). Большая часть дополнительной арифметики приходится на работу с высоким разрешением. Замера <=50 мс на H100 здесь нет; качество требует тренировочного эксперимента.

## Запуск

Из корня проекта в окружении `challenges`:

```powershell
& 'D:/Apps/anaconda3/envs/challenges/python.exe' -m src.training --config configs/local.yaml
```

Ноутбук содержит отдельную ячейку подсчёта FLOPs без pretrained download и отдельную ячейку обучения. Реализация сама полный эксперимент не запускает.

Следить за combined AIC, Dice ≤1%, 1–5%, plain×Q×площадь, FPR originals и разницей до/после gate. Наличие локальной auxiliary supervision и соблюдение FLOPs не доказывают прирост качества.

## Проверка реализации

Проверены residual energy до уменьшения, общая геометрия train/val/test и аугментаций, независимый auxiliary gradient, шаг оптимизатора, сохранение/загрузка весов и защита resume. Сквозные проверки включают training/validation/Predictor и сохранённый Segmenter → PNG исходного размера → сверка метрик с CheckpointEvaluator. Используются синтетические данные, competition test не используется.

Полноразмерный CPU forward 640/1024 даёт конечные logits 1×1×640×640. Полное обучение и H100 timing не выполнялись в ходе рефакторинга. Актуальные проверки всей ветки запускаются через pytest.
