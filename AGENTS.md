# Project
It's a python project for making experiments with deep learning models in segmentation competition AIIJC

Project structure:
- `src/` - reusable model/training/data/etc code
- `runs/` - all experimental run logs, results, metric and etc. Contains separate unique folder per each run
- `notebooks/` - notebooks with experimental run pipelines

# Competition rules
Competition rules are in `AIIJC_RULES.md`

# Environment
As python enviroment please use conda enviroment challenges:
``D:\Apps\anaconda3\envs\challenges\python.exe``

# Code
- Follow the existing project structure and style.
- Make a clean and readable code with low cognitive load. Main criteria of good code is when a human can quickly understand what it does.
- When adding new functionality to `src/` package use objective oriented approach (like now)
